# Briefcase

A content workflow toolkit for writers and marketers.

## What it does

- Generate content briefs from rough ideas
- Repurpose existing content into new formats
- Get content ideas from the Idea Drawer
- Copy or download outputs as TXT, PDF, or PNG

## Live Tool

[Open Briefcase](https://github.com/anugrahaa0506-cloud/Briefcase-tool-)

## Built with

HTML, CSS and JavaScript.

## About

Built to make everyday content workflows faster and more structured.
