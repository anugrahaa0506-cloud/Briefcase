# Briefcase

A lightweight content workflow toolkit for writers and marketers.

## What it does

- Generate structured content briefs from rough ideas
- Repurpose existing content into new formats
- Generate content prompts with the Idea Drawer
- Copy or download outputs as TXT, PDF, or PNG

## Built with

HTML, CSS and JavaScript.
